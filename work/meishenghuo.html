欢乐美生活 · 社区商城小程序 — 2020–22

为社区商城打造 IP 与设计规范，
让拉新和日活一起增长

观看交互演示↓

Intro · 项目背景

欢乐美生活是恒荣科服旗下的社区生活服务平台，以集团「美好生活领跑者」的愿景为核心，为住宅、商业、校园三大智慧园区提供居家全服务。

我负责美生活商城小程序的整体用户体验设计，搭建了商城的品牌系统，包括 IP 形象与设计规范；与产品、技术团队协作推进落地，持续关注数据与用户反馈，用设计语言传达产品价值。

问题

商城需要在园区业主中拉新、促活；多人协作的页面越来越多，风格与组件容易不统一，设计与开发对接成本高；品牌也缺少一个能和用户建立情感连接的记忆点。

方案

用设计思维模型规划流程，通过五个维度的竞品分析与用户体验地图找到优化方向；搭建小程序设计规范；设计「欢乐美生活」IP 形象，并延展到线上线下各个触点。

结果

结合业务目标设计活动落地页，活动拉新率提升 20%，线上日活用户新增 8%；统一的设计规范提升了团队协作与开发对接效率；IP 形象强化了品牌辨识度与亲和力。

设计过程 · Process

01 · Design thinking · 设计思维模型

以设计思维为核心，把产品与开发一起纳入考量

整个项目按「项目研究 › 调研分析 › 架构交互 › 设计搭建 › 视觉设计 › 复盘汇总」推进。设计思维之外，同时兼顾产品思维（用户调研、竞品分析、产品体验、增长导向）与开发思维（设计落地、团队协同），让方案既好用、又能落地。

02 · Competitive analysis · 竞品调研

五个维度的竞品分析，先看清方向再动手

对直接竞品和间接竞品，从体验环境（情感化、友好度、微交互、信息布局、容错机制）、市场状况（市场容量、竞争格局、市场占有率）、需求分析与商业模式等维度进行拆解。

这能有效帮助确定设计方向和设计规范，避免常规问题。

03 · Design guidelines · 设计规范

一套小程序设计规范：提效、协作、一致、品牌

通过制定设计规范体系提高工作效率与团队协作能力，统一产品风格；遵循用户行为习惯、降低学习成本，统一品牌基调，提高开发效率，确保设计的一致性。

规范化、标准化、品牌统一之上，我们继续探索设计的情感温度、视觉细节、元素质感与界面的降噪简约。

规范不是限制，而是让团队把精力留给真正需要设计的问题。

04 · User experience map · 用户体验地图

用体验地图找到流失点，制定用户增长策略

用户体验地图是用户增长策略体系的重要方法之一：模拟不同用户群体的操作行为，梳理每个阶段的行为、触点、痛点与情绪曲线，从而优化用户体验。

同时这也是一次对用户心智的调查分析，最后让团队达成共识，推进优化方向。

05 · IP design · IP 形象

设计一个会打招呼的 IP，拉近与业主的距离

IP 形象的设立，旨在满足情感化设计需求，提高产品的亲和力，拉近与用户之间的距离，形成产品独有的品牌感。

我为它设计了不同视角下的形象与一组基础动作，适用于线上线下不同场景——不同的动态形象，传达不同的状态。

06 · IP extension · 场景延展

从缺省页到门店物料，IP 出现在每一个触点

结合社区服务的不同场景，延展出一系列身份形象，应用于线上线下物料、缺省页、首页 banner 等场景，让品牌在每个触点都保持一致又有温度。
